# Changelog

## Unreleased

First public version, for LÖVE 11.5.

- Project launcher with per-project configuration, settings and input actions.
- 2D showcase with a small shooter, font rendering, rich-text markup and the
  UI editor.
- 3D showcase: a sandbox on the Robot 64 Engine place using the RBX renderer,
  physics and character controller.
- Optional RBX renderer and rigid-body physics, with regression suites
  (`RBX_TEST=1 love .`).
- `bootstrap.lua` for using the engine as a Git submodule of another project.
- `WAVE_SMOKE_FRAMES` for scripted start-up checks.
