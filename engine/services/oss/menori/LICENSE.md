# Menori license

Menori, a LÖVE library for 3D and 2D rendering based on a scene graph, is
written by rozenmad (https://github.com/rozenmad/Menori). The upstream
README declares the library MIT licensed; the repository does not publish a
separate license file or copyright line, so the copyright line below is taken
from the authorship stated in the source headers.

The vendored copy is used by the optional RBX renderer
(`engine/graphics/rbx/runtime/backend/menori.lua`). Files under `modules/ml`
and `modules/libs` keep their own headers (CPML-derived math, rxi's json.lua).
