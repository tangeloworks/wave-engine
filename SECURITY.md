# Security policy

Fixes are made on the `main` branch; there are no separately maintained
release branches yet.

Please report vulnerabilities privately through GitHub's
**Security → Report a vulnerability** form on this repository rather than in
a public issue. Include the affected file or module, the LÖVE version, and
the steps or a small project that reproduces the problem.

Areas where a report is most useful: the optional networking module, place
and mesh file parsing (`engine/graphics/rbx`), saved settings, and anything
that reads files or URLs supplied by a player.
